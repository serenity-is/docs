# FormScriptAttribute.Key property

Gets the key. If no key is set, and InferKey is true, the key will be inferred automatically from the type name, module name and namespace. If InferKey is false, the key is full type name of the type this attribute is placed on.

```csharp
public string? Key { get; }
```

## Property Value

The key.
