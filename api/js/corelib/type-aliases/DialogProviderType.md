Identifies the underlying UI provider that backs a [Dialog](../classes/Dialog.md) instance.
- `"bsmodal"` — Bootstrap modal (`.modal`).
- `"uidialog"` — jQuery UI dialog (`.ui-dialog`).
- `"panel"` — Inline Serenity panel (`.s-Panel`).
