# UniqueConstraintAttribute.DisableDefaultBehavior property

Gets or sets a value indicating whether the default [`UniqueConstraintSaveBehavior`](../../Serenity.Services/UniqueConstraintSaveBehavior.md) pre-check should be disabled for this constraint. Set to `true` if you want to replace the default behavior with your own.

```csharp
public bool DisableDefaultBehavior { get; set; }
```
