# ReflectionOptionsSetter

Reflection-based helper that applies option objects to widgets using members
decorated with [OptionAttribute](../../../classes/OptionAttribute.md). Handles PascalCase → camelCase mapping
and getter/setter (`get_*`/`set_*`) conventions.
