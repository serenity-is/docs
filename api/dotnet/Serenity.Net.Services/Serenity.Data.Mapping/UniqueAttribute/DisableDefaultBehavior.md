# UniqueAttribute.DisableDefaultBehavior property

Gets or sets a value indicating whether the default [`UniqueFieldSaveBehavior`](../../Serenity.Services/UniqueFieldSaveBehavior.md) pre-check should be disabled for this field. Set to `true` if you want to replace the default behavior with your own.

```csharp
public bool DisableDefaultBehavior { get; set; }
```
