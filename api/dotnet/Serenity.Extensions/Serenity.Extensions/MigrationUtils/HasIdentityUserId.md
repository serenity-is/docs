# MigrationUtils.HasIdentityUserId method

Returns true if the user IDs are generated by the database, e.g. an identity column, which is the case for Int32Field and Int64Field IDs.

public static bool HasIdentityUserId(this IOptions<UserEntityOptions>? userEntityOptions)
