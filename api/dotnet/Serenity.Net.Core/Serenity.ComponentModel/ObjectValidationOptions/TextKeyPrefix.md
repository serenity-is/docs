# ObjectValidationOptions.TextKeyPrefix property

Gets or sets the local text key prefix of the properties, which the implied text keys of the messages of their rules start with, e.g. `Forms.Northwind.Customer.`, by default the one of the form or columns of the [`RulesType`](./RulesType.md), if it is one.

```csharp
public string? TextKeyPrefix { get; set; }
```
